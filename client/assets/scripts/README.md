# scripts

- `core/` 启动、会话（Boot、Session）
- `net/` 网络状态机、MockTransport（带 MockGameSession）、录包回放、P0 协议 stub（`net/protocol/`，不连真服）
- `config/` JSON 读表
- `module/` 业务系统（`mainline/` 主线战报，`idle/` 挂机收益，`hero/` 英雄升级，`summon/` 召唤，`smith/` 铁匠铺强化，`arena/` 竞技场）
- `ui/` 页面栈、弹窗队列、Toast、主城壳（顶栏 / 底栏 / `PanelNav`）、安全区（`SafeArea.ts`）

场景在 `assets/scenes/`。Boot / Main / Battle 已建好。Boot 的 Canvas 上已经挂了 Boot。其余界面由代码生成，不用再挂组件。

## 倩：预览 Boot → Main

Boot 场景的 Canvas 上已经挂了 **Boot**。拉最新代码后直接预览即可，不用改场景，也不用再挂组件。

1. Creator 3.8.8 打开 `client`。
2. 启动场景保持 Boot，点预览。
3. 屏幕上是 Mock 登录面板：账号、密码（可留空）、三个服务器（本地Mock / 提审 / 正式占位）。账号默认 `mock`（或上次记下的账号）。点一个服务器，再点 **进入游戏**。
4. 应进入 Main。顶栏左侧是角色名、等级、所选服务器和开服天，右侧是金币、钻石，例如 `MockHero Lv1`、`本地Mock · 开服D1`、`金币 100`、`钻石 20`。底栏是主城 / 英雄 / 召唤 / 铁匠铺 / 玩法。画面中间是「主线 · 第N关」，下面是「挂机」，旁边有日志、公告、模拟断线。Main 场景不用事先摆 UI；Boot 发现 Canvas 上没有 MainApp 会自己补上。
5. 控制台标记：`[Boot] stage=version` → `hot-update` → `config` → `login` → `enter-main`，以及 `[Net] connect mock://local`、`[Config] loaded`。这些行现在带 `[mxzg]` 前缀，例如 `[mxzg][info][Boot] stage=version`。

可选：

- Boot 上勾选 `skipLogin`：不显示面板，仍用检查器里的账号进 Main。该账号在 Mock 里没有角色时，用账号名自动创角，不会停在创角面板。
- `account` 默认 `mock`，可在检查器里改。面板会优先填上次登录的账号。
- 从 Boot 进 Main 即可。没有 Boot 时账号是空的，主线和挂机会提示网络未连接。
- 背包在底栏「玩法」里。打开后点返回关掉。公告：连续入队两张弹窗。模拟断线：看主城「网络」从 connected 到 reconnecting 再回到 connected。主线进度在断线后还在。
- 主线：点「主线 · 第N关」打开关卡列表，挑战后看战报再结算。详见下面 C3。
- 发布构建前，构建场景列表要包含 Boot 和 Main，启动场景为 Boot。

热更和真 socket 都不在这一步。网络是 `mock://local`。

## 安全区（B8）

设计分辨率保持 **720×1280**（`settings/v2/packages/project.json`）。运行时不改 Fit Width / Fit Height。

`ui/SafeArea.ts` 在 Boot 和主城 `start` 时读可见区域与 `sys.getSafeAreaRect()`，窗口变化后再算。登录面板、主城按钮和 Toast 会让开刘海；安全区比设计分辨率小时只缩小不放大。不用改 `.scene`，也不要给 Canvas 再挂引擎自带的 SafeArea。

`GameLog` 的 `minLevel` 为 `debug`（默认）时，左上角有一行尺寸。桌面没有刘海时，控制台执行 `localStorage.setItem("mxzg.safe", "88,0,34,0")` 再拖一下窗口。说明见 `docs/safe-area.md`。

## 账号 / 选服 / 创角（C1）

登录面板在 Boot 的安全区里用代码生成，不改 `.scene`。密码只是占位，Mock 不校验，也不写进本地。

选服三个：`本地Mock`（id 1）、`提审`（id 2）、`正式占位`（id 3）。点中的会随 `Proto.login` 的 `serverId` 记下，主城标题下显示这个名字。三个服共用这一局里的一个角色槽；换服不另开角色，换账号才会被 Mock 看成「还没有角色」。

- 账号 `mock` 点 **进入游戏**：已有角色 MockHero，直接进主城。
- 点 **创角**，或把账号改成别的名字再点 **进入游戏**：创角面板。确认走 `Proto.roleCreate`，成功后再 `Proto.roleEnter`。
- 创角名字留空或只有空格：Toast「角色名不能为空」，停在创角面板，原来的角色不变。
- **返回** 回到登录面板。
- 登录成功后把账号、服务器写到 `localStorage`（`mxzg.account`、`mxzg.serverId`）。Creator 里优先 `sys.localStorage`。下次打开面板会填上。不记密码，不记角色名（角色在 Mock 进程里，重新预览会回到 MockHero）。

`skipLogin` 仍不显示这两块面板。

## 主线关卡（C3）

不改 `.scene`，不加载 `Battle.scene`，不用新挂组件。战斗和结算都是主城页面栈里代码生成的。

主城点 **主线 · 第 N 关**（网络没连上时 Toast「网络未连接」，不进列表）：

1. **关卡列表**。当前关是「挑战」，前面是「已通关」，后面几关是「未开启」。点未开启 Toast「请先通关第N关」，点已通关 Toast「第N关已通关」。
2. **挑战** 发 `Proto.stageEnter`。画面是双方各三个占位单位、血条和回合战报。可以等它播完，或点 **跳过**。
3. **结算**。胜利显示奖励（Mock 主线是金币 +10），顶栏等级、金币、开服天跟着变。**下一关** 直接再进战；**关卡列表** 看新进度；**返回主城** 回到主城，按钮上的关卡号已更新。
4. 战斗中 **撤退** 发 `stage.result` 且 `win: false`。Toast「第N关挑战失败，进度不变」，结算是失败，金币不加，可 **再次挑战**。列表不让跳关。战报函数里，关卡号高于等级会判负（自检覆盖）；界面打当前关时仍判胜，避免进度卡住。Mock 传输层仍允许跳关。
5. 自然推进时下一关号等于等级，战报判胜，所以可以一直推到第 70 关（七日目标要的进度）。满 4 胜后等级到 5，铁匠铺解锁；满 5 胜后开服天到 D2，金币 150。

断线重连后进度还在。协议号没有改。

## 挂机（C4）

不改 `.scene`，不用新挂组件。挂机页在主城页面栈里用代码生成。

主城点 **挂机**（网络没连上时 Toast「网络未连接」，不进页面）。玩法列表第一项也是挂机，不带锁。

1. **时长**。从这次预览的 Mock 会话开始，或从上次领取、创角起算。断线重连不清零。上限 **8 小时**，超出的时间丢掉。画面是 `已挂机 时:分:秒 / 08:00:00`，大约每秒跳一次。
2. **收益预览**。金币和强化石按**当前已通关关数**乘整段时长。未通关：每分钟 6 金币，每 30 秒 1 个强化石。每多通关 1 关，每分钟金币 +4，强化石间隔缩短 1 秒（最短 10 秒）。刚进来可能是 0。下面还有一行「挂满 8 小时约可领」，通关后这行会变大。
3. **领取**。大约 10 秒后金币至少 +1。点领取，Toast「领取成功：金币 +N」，顶栏金币增加。强化石大约 30 秒 1 个，领到后页面写「已有强化石」。回到背包能看到这些强化石，点使用会提示不能直接使用。马上再点领取：Toast「挂机时间太短，暂无收益」，金币不变。
4. **快速作战**。按钮是「快速作战 · 第N关」。点一下直接结算当前关，**不播**主线战报。Toast「快速作战：第N关胜利，金币 +10，下一关 N+1」。顶栏等级、金币和主城按钮上的关卡号跟着变。可以连续点。挂机计时不会被这次结算清掉；通关后，同一段时长按新的已通关关数重算。
5. 创角会把挂机时长和强化石清掉，钱包回到金币 100、钻石 20。

不需要起 server，也不用改场景。

## 英雄（C5）

不改 `.scene`，不用新挂组件。英雄列表和详情在主城页面栈里用代码生成。挂机按钮还在主城，玩法列表里的挂机也还在。下面的金币和等级按还没使用背包里的金币袋、经验药水来算。

底栏点 **英雄**（主线 Lv1 就开。网络没连上时 Toast「网络未连接」，不进列表）：

1. **列表**。默认三名：光耀骑士（3星）、林间游侠（2星）、星辉法师（1星），都是 Lv1。空名册也会种下这三名。点一行进入详情。
2. **详情**。名字、`LvN · N星`、攻击 / 生命 / 防御（占位，升级后变高），以及「武器 新手短剑 Lv1 · 攻击 +0」。星级只展示，本页不升星。武器到铁匠铺强化，升级不改武器。没强化过时攻击和以前一样。
3. **升级**。按钮写着消耗，例如「升级（金币 30）」。Lv1→2 花 30，之后每级再多 20（Lv2→3 为 50）。点下去 Toast「光耀骑士升至 Lv2，消耗金币 30」。顶栏金币从 100 变成 70。详情上的等级、属性和「持有金币」一起变。点 **返回** 回到列表，这一行已是 Lv2。再返回回到主城，底栏回到「主城」。
4. **金币不足**。起步 100 金可以升两次（30 + 50），第三次需要 70。Toast「金币不足，升级需要 70」，等级和顶栏金币都不变。
5. **已满级**。最高 Lv10。再点 Toast「已达最高等级」，金币不扣。
6. 从详情或列表点底栏其它入口，会先回到主城再打开那一项。创角会把英雄等级和钱包重置（金币 100、钻石 20）。

不需要起 server，也不用改场景。

## 召唤（C6）

5. **十连**。钻石够 90 时一次抽 10 张，Toast「十连完成，新英雄 N，碎片 M」。不够则整次不做。顺序固定，抽完从头循环。创角会把钻石、名册和召唤进度重置。

不需要起 server，也不用改场景。

## 背包（C7）

不改 `.scene`，不用新挂组件。背包页在主城页面栈里用代码生成。召唤、英雄升级和挂机入口都还在。

主城点 **背包**（`opencondition` 里是主线 Lv1，新号直接能进。网络没连上时 Toast「网络未连接」，不进页面）。玩法列表里的「背包」也进同一页；等级不够时按钮仍显示「锁·背包」，点击只 Toast「背包未开启，需要主线达到 Lv1」，和铁匠铺同一套。

1. **列表**。新号有小金币袋 ×2、经验药水 ×2。点一行变成「已选」。下面写着说明和持有数量。
2. **小金币袋**。点 **使用**。Toast「使用成功：金币 +50」。顶栏金币从 100 变成 150，背包里变成 ×1。再用一次后这一格消失。
3. **经验药水**。点 **使用**。Toast「使用成功：光耀骑士升至 Lv2」。金币不变。到底栏 **英雄**，光耀骑士已是 Lv2，仍可以用金币按新等级升级（Lv2→3 花 50）。若已经用金币升过，就在当前等级上再升 1 级。领队已满级时 Toast「光耀骑士已达最高等级，无法使用」，药水不扣。

7. 创角会清掉强化石和碎片，并重新放上小金币袋 ×2、经验药水 ×2。钱包回到金币 100、钻石 20，英雄回到起步等级。

不需要起 server，也不用改场景。

4. **全部领取**。还有未领附件时，按钮是「全部领取（N）」。新号只领开服补给这一封，Toast 和单封领取一样。领完再点，Toast「没有可领取的附件」。欢迎信如果还没点开，仍是未读。
5. **维护公告**。一开始就是已读，没有附件。点领取同样 Toast「这封邮件没有附件」。
6. **背包**。领完再进背包。小金币袋从 ×2 变成 ×3，多出强化石 ×3。小金币袋仍可使用，加金币。强化石点使用仍提示不能直接使用。
7. **删除**。开服补给还没领时点 **删除**，Toast「请先领取附件再删除」，信还在。领过之后，或欢迎、公告这种没有附件的，可以删除，Toast「已删除：标题」。
8. 创角会把邮箱重置回这三封，钱包回到金币 100、钻石 20，领过的强化石清掉，背包重新放上小金币袋 ×2、经验药水 ×2。

## 铁匠铺（C9）

不改 `.scene`，不用新挂组件。铁匠铺在主城页面栈里用代码生成。邮件、背包、英雄升级和挂机入口都还在。底栏锁还是主线 Lv5，没有绕过。

**先开锁。** 新号是 Lv1，底栏是「锁·铁匠铺」。点它只 Toast「铁匠铺未开启，需要主线达到 Lv5」，不进面板。等级 = 1 + 已通关关数。下面两条都能到 Lv5：

1. 主城点 **主线**，把第 1 关到第 4 关各打赢一次。第 4 胜后顶栏是 Lv5。
2. 或者主城点 **挂机**，连续点 4 次 **快速作战**。每次结算当前关，不播战报。第 4 次后顶栏同样是 Lv5。

回到底栏，「铁匠铺」不再带锁。Lv4 及以下仍然带锁。

**再拿强化石。** 主城点 **邮件**，领取「开服补给」，得到强化石 ×3，顶栏金币 +80。也可以挂机大约 30 秒再领取，至少 1 个强化石。背包里点强化石仍然提示不能直接使用。

底栏点 **铁匠铺**（网络没连上时 Toast「网络未连接」，不进页面）：

1. **起步武器**。三名英雄各有一把「新手短剑 Lv1」，攻击加成为 0。没有武器的英雄会在创角或第一次打开本页时补上，不扣金币也不扣石头。默认选中领队光耀骑士。
2. **强化**。Lv1→2 花 20 金币和 1 个强化石，攻击 +8。之后每级金币再多 10，强化石仍是 1 个。最高 Lv10。按钮写着消耗，例如「强化（金币 20 · 强化石 ×1）」。
3. **成功**。按上面的路径（4 胜、领邮件、再强化一次）：Toast「强化成功：光耀骑士的新手短剑升至 Lv2，消耗金币 20、强化石 ×1」。顶栏金币减少 20。页面上的攻击、武器等级和持有强化石一起变。
4. **强化石不足**。石头用完再点，Toast「强化石不足，强化需要 1」。武器等级和金币都不变。
5. **金币不足**。金币不够时 Toast「金币不足，强化需要 N」。武器和强化石都不变。
6. **已满级**。升到 Lv10 再点，Toast「武器已达最高强化」，不扣材料。
7. **英雄和背包**。点底栏 **英雄**，光耀骑士那一行带「武器Lv2」。详情里攻击比未强化时高 8，并写「武器 新手短剑 Lv2 · 攻击 +8」。再进背包，强化石少 1 个。英雄升级仍然只花金币，不改武器。
8. 换一名英雄再强化，只动那一名的剑。创角会把武器重置回 Lv1，并清掉领过的强化石。

## 竞技场（C10）

不改 `.scene`，不用新挂组件。竞技场在主城页面栈里用代码生成。铁匠铺、邮件、背包、英雄升级和挂机入口都还在。锁还是玩法列表里的「竞技场」，条件是 `opencondition` 的 `main_pvp`，主线 Lv8。没有绕过，也没有单独的主城按钮。

**先开锁。** 新号是 Lv1。底栏点 **玩法**，列表里是「锁·竞技场」。点它只 Toast「竞技场未开启，需要主线达到 Lv8」，不进面板。等级 = 1 + 已通关关数。Lv7 仍然带锁。下面两条都能到 Lv8：

1. 主城点 **主线**，把第 1 关到第 7 关各打赢一次。第 7 胜后顶栏是 Lv8。
2. 或者主城点 **挂机**，连续点 7 次 **快速作战**。每次结算当前关，不播战报。第 7 次后顶栏同样是 Lv8。

第 5 胜时开服天会到 D2（每 5 关 +1）。这只影响竞技场的「今日次数」按哪一天计算，到达 Lv8 时次数仍是满的 5 次。回到 **玩法**，「竞技场」不再带锁。若玩法页是在升级前打开的，先返回再进一次，锁的文案才会刷新。

玩法里点 **竞技场**（网络没连上时 Toast「网络未连接」，不进页面）：

1. **自己的占位。** 积分 1000，约第 41 名，战力是三名起步英雄的攻击之和（165，含武器；Lv1 新手短剑不加攻击）。约排名由积分换算，不是真实排行榜。
2. **对手。** 固定五名，从上到下：见习剑士、流浪佣兵、铁壁守卫、银月骑士、冠军候补。战力够的标「可胜」，不够的标「较难」。起步名册能胜前两名。点一行变成「已选」。
3. **挑战。** 按钮写着「挑战见习剑士（剩余 5）」。点一下直接结算，**不播**主线战报。胜利 Toast「挑战胜利：击败见习剑士，积分 +24，金币 +20」。顶栏金币从当前值再加 20。页面上的积分、约排名和「今日剩余」一起变。
4. **失败。** 选铁壁守卫再挑战。Toast「挑战失败：不敌铁壁守卫，积分 -12」。金币不加。积分最低到 800，再输会 Toast「积分没有再降」。
5. **今日 5 次。** 第 6 次点挑战，Toast「今日挑战次数已用完」。积分和金币不变。次数跟着 Mock 的开服天走：再打主线把开服天加 1（每 5 关一次）后，剩余回到 5。创角把积分重置回 1000，次数清零。
6. **战力。** 英雄升级或铁匠铺强化会提高攻击，竞技场战力跟着变。强化不改积分。挑战不改英雄等级、武器、钻石、挂机计时和主线进度。

不需要起 server，也不用改场景。
