# 本地 Mock 会话与录包回放（B6）

没有 Java 服时，编辑器预览仍然只走 `MockTransport`。不需要另起进程，也没有 `npm run mock-server`。

要连本机游戏服时，预览地址加 `?transport=ws`（`http://127.0.0.1:7456/?transport=ws`）。那一步走 `ws://127.0.0.1:13111/game` 桥到 TCP 9902，不替换这里的 Mock 会话，也不直连 13101。见 `docs/h5-websocket.md`。

假服状态在 `MockGameSession` 上，和传输绑在一起。同一次预览里多次请求共用这一份：登录、创角、主线连打都会改它。断线重连不新建会话，进度还在。

## 默认路径

`NetClient.shared` 自己 `new MockTransport()`。Boot 的 Mock 登录和主城「主线」都走它。

一局开始时：

| 字段 | 初值 |
|------|------|
| 角色 | `1001 / MockHero / Lv1` |
| `stageId` | 1（下一关） |
| `clearedStage` | 0 |
| `openDay` | 1 |
| 金币 / 钻石 | 100 / 20 |
| 英雄 | 光耀骑士 3星、林间游侠 2星、星辉法师 1星，都是 Lv1 |

规则：

- `login` 记下账号和 `serverId`，token 固定 `mock-token`。不重置角色和主线。
- 默认角色属于账号 `mock`。还没登录，或登录账号就是所属账号时，`role.enter` 回当前角色，并带 `openDay`、`stageId`、`gold`、`diamond`。登录别的账号时 `hasRole` 为 false，金币钻石回 0，不改掉已有角色。`role.create` 成功后角色改归当前登录账号。Boot 在有角色时把结果写进 `Session`（含所选服务器名和钱包）。
- `role.create` 名字去空白后为空则拒绝，不改状态。成功则改名，`roleId` 仍是 1001，主线、等级、开服天回到新号，钱包回到金币 100、钻石 20，挂机时长、强化石、挂机领取次数和召唤碎片清掉，背包重新放上小金币袋 ×2 和经验药水 ×2，英雄回到起步三名 Lv1 且新手短剑 Lv1，邮箱回到起步三封，竞技场积分回到 1000、今日次数清零，幻境之塔回到第 1 层、今日次数清零，金币副本今日次数清零，七日登录回到第 1 天且已领记录清掉，七日目标已领记录清掉，商店今日已购清掉，许愿次数和游标清掉，咖啡馆次数和未领取的招待清掉，礼包的升级领取、每日已购、首充和累充清掉。
- `stage.enter` 的 `stageId < 1` 失败。成功回 `battleId`，形如 `mock-battle-<关卡>-<序号>`。Mock 仍允许跳关，方便自检。主线界面只放行下一关（C3）。
- `stage.result` 胜利且关卡高于已通关：`clearedStage` 推进，`level = 1 + clearedStage`，`openDay` 至少为 `1 + floor(clearedStage / 5)`（只升不降）。`nextStageId = clearedStage + 1`。奖励占位 `{ id: 1, count: 10 }`，id 1 加金币、id 2 加钻石。失败停在本关，奖励空，进度和钱包不变。回包带结算后的 `gold` / `diamond`。不改挂机起算时刻。第 70 关之后仍按同一条规则。
- `stage.push` 调试用。缺省把已通关连胜推到第 70 关，每一关金币 +10，等级和开服天跟一关关打相同。已经到了不加金币。不改挂机起算和角色登录天。开服天变了之后，竞技场、幻境之塔、金币副本的今日次数留到下次进入再清零。默认录包没有这条；预览仍走 MockTransport。
- `idle.query` / `idle.claim`：时长从会话创建、上次领取或创角起算，上限 8 小时。收益按当前已通关关数乘整段时长。领取把金币和强化石（id 101）写入会话。不够 1 个单位时拒绝。创角清空强化石并重新起算。断线重连沿用同一会话，时长还在。
- `hero.list` / `hero.upgrade`：名册空时种下起步三名。升级只扣金币、升 1 级，星级不变，不动挂机计时和主线。金币不足、满级或没有这名英雄时拒绝。默认录包没有这两条；预览仍走 MockTransport。
- `summon.pull`：单抽扣 10 钻石，十连扣 90。新英雄追加到名册，重复转碎片（id = 40000 + 英雄 id，每次 +10）。钻石不足或次数不是 1/10 时整次拒绝。创角把召唤游标和碎片清掉。默认录包没有这条；预览仍走 MockTransport。
- `bag.list` / `bag.use`：列出数量大于 0 的道具。新号自带小金币袋 ×2（每个 +50 金币）、经验药水 ×2（给名册第一名 +100 经验，满 100 升 1 级）和许愿符 ×2。强化石、许愿符和碎片不能直接使用。空背包、数量不足、领队满级时拒绝。创角清掉强化石和碎片后重新发起步消耗品。默认录包没有这两条；预览仍走 MockTransport。
- `mail.list` / `mail.read` / `mail.claim` / `mail.claimAll` / `mail.delete`：新号三封。欢迎和开服补给未读，维护公告已读且没有附件。领取把金币写入钱包、道具写入背包，并标成已领取。没有附件或已经领过会拒绝。未领附件不能删。创角把邮箱重置回这三封。默认录包没有这些消息；预览仍走 MockTransport。
- `smith.view` / `smith.strengthen`：每名英雄一把新手短剑。打开时给没有剑的英雄补 Lv1，不扣费。强化扣金币和 1 个强化石，攻击随剑等级提高。金币或强化石不足、已满级、没有这名英雄时拒绝。创角把剑重置回 Lv1。默认录包没有这两条；预览仍走 MockTransport。入口仍是主线 Lv5。
- `arena.view` / `arena.challenge`：积分从 1000 起，约排名由积分换算。对手固定五名。战力不低于对手则胜，积分 +24、金币 +20；否则积分 -12。每天 5 次，开服天变化时次数清零。没有对手或次数用完时拒绝。创角把积分和次数重置。默认录包没有这两条；预览仍走 MockTransport。入口仍是主线 Lv8。
- `tower.view` / `tower.challenge`：从第 1 层打到第 20 层。战力不低于守关则胜，层数 +1，金币按层发放，强化石 +1；否则层数不变。每天 10 次，开服天变化时次数清零、层数保留。已到塔顶或次数用完时拒绝。创角把层数和次数重置。默认录包没有这两条；预览仍走 MockTransport。入口仍是主线 Lv16 的幻境之塔，不是开服第 30 天的幻魔塔。
- `daily.view` / `daily.challenge`：只做金币副本，三档难度。战力不低于建议值则胜，按该档发金币；普通和困难再发强化石，失败不发奖励。每天 2 次，开服天变化时次数清零。没有这个难度或次数用完时拒绝。创角把次数清零。默认录包没有这两条；预览仍走 MockTransport。入口是主线 Lv15 的日常副本（`main_mission`），不看开服天。经验副本和英雄副本不在这里。
- `login7.view` / `login7.claim` / `login7.advance`：七日登录按角色登录天，新号第 1 天。领取把金币钻石写入钱包、道具写入背包。未到或已领会拒绝。`login7.advance` 把登录天 +1，最多第 7 天，不改开服天，也不自动领取。主线胜利只加开服天，不加登录天。创角把登录天和已领记录清掉。默认录包没有这三条；预览仍走 MockTransport。主城按钮和玩法列表都能进，不设等级锁。
- `goal7.view` / `goal7.claim`：七日目标按当前会话算进度。通关数看 `clearedStage`，召唤看成功抽出的卡数，升级看名册高出 Lv1 的等级之和（英雄页和经验药水都算），挂机看成功领取次数。早期任务是通关第 1/3/5 关、召唤 1 次、升级 1 次、领取挂机 1 次。第 7 日通关第 70 关在通关数到 70 之前拒绝领取。没完成、已领取或没有这个 id 也拒绝。成功把金币钻石写入钱包、道具写入背包，不改主线和登录天。创角清掉已领记录和挂机领取次数。默认录包没有这两条；预览仍走 MockTransport。主城按钮和玩法列表都能进，不设等级锁。
- `shop.view` / `shop.buy`：基础商店卖强化石、小金币袋和经验药水。强化石和经验药水扣金币，小金币袋扣钻石，买到的进背包。不够钱或今日售罄时拒绝。每天限购随开服天清空，已经进背包的不收回。创角把已购次数清掉。默认录包没有这两条；预览仍走 MockTransport。样例 opencondition 没有商店行，主城按钮和玩法列表都能进，不设等级锁。召唤仍直接花钻石。
- `wish.view` / `wish.draw`：低级许愿池花金币 30、许愿符 ×1 或钻石 5，按固定 10 格发奖励。前 9 格是金币、强化石、经验药水，第 10 格是钻石 8。每天 5 次，三种方式共用，开服天变化时次数清零、游标保留。方式不对、次数用完或花费不够时拒绝。创角把次数和游标清掉。默认录包没有这两条；预览仍走 MockTransport。入口是主线 Lv10 的许愿池（`main_blessingpool`），不看开服天。9 胜或 9 次快速作战到 Lv10，第 8 胜只到 Lv9。高级许愿池不在这里。

- `gift.view` / `gift.claimLevel` / `gift.buyDaily` / `gift.recharge` / `gift.claimAcc`：一个礼包入口里的升级有礼、每日礼包、首充和累充。升级有礼按主线等级领 Lv5/10/15，各一次。每日礼包花 10 钻石，一天一次，开服天变化后可再买，不计入累充。`gift.recharge` 的 `kind` 为 `first` 时只完成一次首充，累充 +6，并发钻石和经验药水；为 `acc` 时每次累充 +30 并发钻石。累充达标领 6/30/68。等级不够、已领取、今日已买或钻石不足时拒绝。不是真实支付。创角把这些记录清掉。默认录包没有这五条；预览仍走 MockTransport。样例 opencondition 没有礼包行，主城按钮和玩法列表都能进，不设等级锁。
- 心跳和其它 cmd 不改进度。其它 cmd 仍 echo。

`openDay` / `stageId` / `level` / `gold` / `diamond` 是 Mock 多带的字段。真服可以不带，调用方用缺省值。

## 录包

文件：`client/assets/resources/mock/session-login-stage.json`

- `session`：喂给 `new MockGameSession(fixture.session)` 的初始进度。
- `steps`：按顺序的回包（`login`、`role.enter`、`role.create`、`stage.enter`、`stage.result`）。`ReplayTransport` 只看 cmd 顺序，不看请求体，也不会按上面的公式重算。

心跳不在录包里，传输层自己回 `serverTime`。cmd 和下一步不一致时不前进。步数走完后再请求，回 `ok: false`。

默认预览不读这个 JSON。要回放时：

```typescript
import { NetClient } from "./NetClient";
import { loadMockFixture } from "./MockFixtureLoader";
import { ReplayTransport } from "./ReplayTransport";
import { Proto } from "./protocol";

const fixture = await loadMockFixture();
const net = new NetClient(new ReplayTransport(fixture));
await net.connect("replay://local");
const login = await Proto.login({ account: "mock" }, net);
```

`loadMockFixture()` 走 `resources.load("mock/session-login-stage")`。Node 自检直接读该 JSON 文件。

## 主城「主线」

Boot 进 Main 之后，点 **主线 · 第 N 关** 打开关卡列表，挑战当前关。先 `Proto.stageEnter`，播一段简化战报，再 `Proto.stageResult`。胜利 `win: true`，Toast 和结算都给出奖励；顶栏等级、金币和「Lv / 开服D」跟着会话变。撤退是 `win: false`，Toast「挑战失败，进度不变」，金币不加。第 4 胜后等级到 5，底栏铁匠铺解锁；第 5 胜后等级到 6、开服天到 2、金币 150。连胜可以推过第 70 关。列表上的 **推关到70（调试）** 走 `Proto.stagePush`，一次补到第 70 关，不播战报。

界面不让跳关。Mock 的 `stage.enter` 仍接受更高的关卡号，自检和录包还走这条。

只预览 Main、没有从 Boot 连上 Mock 时，按钮提示网络未连接。

## 主城「挂机」

点 **挂机** 打开收益页：时长、当前可领、挂满 8 小时的预览。领取走 `Proto.idleClaim`，顶栏金币跟着变。**快速作战** 对当前关发 `stage.enter` 再 `stage.result`（`win: true`），不播战报。**推关到70（调试）** 和主线列表是同一个 `stage.push`。默认录包没有这两条挂机消息，也没有 `stage.push`；预览仍走 MockTransport。

## 主城「英雄」

底栏点 **英雄** 打开名册，再点一名英雄打开详情。升级走 `Proto.heroUpgrade`，顶栏金币跟着变。返回先回到列表，再回到主城。见 `client/assets/scripts/README.md` 的 C5。默认录包没有英雄消息。

## 主城「召唤」

底栏点 **召唤** 打开召唤页。单抽和十连走 `Proto.summonPull`，顶栏钻石跟着变。新英雄再进 **英雄** 能看到。见 `client/assets/scripts/README.md` 的 C6。默认录包没有召唤消息。

## 主城「背包」

主城点 **背包**，或从玩法列表进入。列表和「使用」走 `Proto.bagList` / `Proto.bagUse`。金币袋刷新顶栏金币；经验药水升级领队，再开英雄列表能看到。强化石和碎片点使用只 Toast。见 `client/assets/scripts/README.md` 的 C7。默认录包没有背包消息。

## 主城「邮件」

主城点 **邮件**，或从玩法列表进入。列表、已读、领取和删除走 `Proto.mailList` / `mailRead` / `mailClaim` / `mailClaimAll` / `mailDelete`。领取补给后顶栏金币增加，再进背包能看到强化石和小金币袋。见 `client/assets/scripts/README.md` 的 C8。默认录包没有邮件消息。

## 倩：Creator 里点一次

1. Creator 3.8.8 打开 `client`。Canvas 上已经有 Boot，不用再挂。
2. 启动场景保持 Boot，预览。
3. 选一个服务器，点「进入游戏」（账号保持 `mock`），进入主城。顶栏应有 `MockHero`、Lv1、所选服务器，以及金币 100、钻石 20。按钮应是「主线 · 第1关」，下面有「挂机」。底栏「铁匠铺」带「锁」。
4. 点主线，再点第 1 关「挑战」。看战报（或点「跳过」）。结算为胜利，Toast「第1关胜利，金币 +10」。点「返回主城」后按钮变成「第2关」，顶栏变为 Lv2、金币 110。
5. 再胜几关。第 4 胜后铁匠铺不再带「锁」。满 5 胜后开服天变为 D2，金币 150。战斗里点「撤退」应 Toast 失败，关卡号和金币不变。
6. 点「挂机」看时长和收益。领取、快速作战见 `client/assets/scripts/README.md` 的 C4。不需要起 server，也不用改场景。
7. 底栏点「英雄」，再点光耀骑士升级。见 README 的 C5。挂机按钮还在主城。
8. 底栏点「召唤」，再点「召唤一次」。见 README 的 C6。然后回「英雄」应能看到霜刃刺客。
9. 主城点「背包」。见 README 的 C7。小金币袋会加顶栏金币，经验药水会让光耀骑士升级。玩法列表里的「背包」进的是同一页。
10. 主城点「邮件」。见 README 的 C8。领取开服补给后顶栏金币增加，背包里多出强化石和小金币袋。玩法列表里的「邮件」进的是同一页。
11. 铁匠铺仍要主线 Lv5。见 README 的 C9：主线或快速作战打赢 4 关后底栏开锁，再用邮件里的强化石强化新手短剑。Lv1 点它只 Toast，不进面板。
12. 竞技场仍要主线 Lv8。见 README 的 C10：主线或快速作战打赢 7 关后，玩法列表里的「竞技场」开锁。Lv1 到 Lv7 点它只 Toast，不进面板。
13. 日常金币副本仍要主线 Lv15。见 README 的 C12：主线或快速作战打赢 14 关后，玩法列表里的「日常副本」开锁。Lv1 到 Lv14 点它只 Toast，不进面板。第 13 胜只到 Lv14。幻境之塔仍要第 15 胜（Lv16）。
14. 主城「七日登录」旁边是「七日目标」。见 README 的 C14。第 7 天应是「通关主线第70关 · 未开启」。没打过第 1 关就领，会 Toast 尚未完成。
15. 主城「七日目标」旁边是「商店」。见 README 的基础商店。买强化石后顶栏金币减少，背包里能看到。玩法列表里的「商店」进的是同一页，不带锁。
16. 许愿池仍要主线 Lv10。见 README 的许愿池低级：主线或快速作战打赢 9 关后，玩法列表里的「许愿池」开锁。第 8 胜只到 Lv9，点它只 Toast，不进面板。开锁后金币许愿会刷新顶栏，许愿符许愿会改背包。
17. 咖啡馆仍要主线 Lv12。见 README 的咖啡馆：主线或快速作战打赢 11 关后，玩法列表里的「咖啡馆」开锁。第 10 胜只到 Lv11，点它只 Toast，不进面板。开锁后派出英雄再领取，顶栏金币增加，背包里出现咖啡豆。
18. 主城「礼包」下面是「限时活动」。见 README 的限时活动。新号用金币兑换会扣金币并得到强化石。点石第一次不扣钻石。限时礼包在开服第 1 天可买，库存 1。玩法列表里的「限时活动」进的是同一页，不带锁。
