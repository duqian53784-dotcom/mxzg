# 出阵维护样板技术证据

本目录保存本批关键运行记录，完整临时日志/截图仍在 `client/temp/project-checks`。人工编辑体验尚待用户验收。

- `local-acceptance.log`：本机 Creator 7456 的真实 UI 点击；包含选服、显式开始、英雄/背包、挂机、出阵草稿取消、切页重开、保存、战斗、结算与刷新恢复。`local-layout.json` 是重开后的实际运行值，不是复制源 JSON。
- `local-expected.json`：交付默认源 Prefab 的 Inspector 参数及 Prefab/Cell SHA256。用于核对字号、按钮位置、列数、间距和星级实际显示。
- `h5-probe-acceptance.log`：独立 18081 的临时布局运行记录，已阻断 7456。临时源修改为字号 44、按钮 `(344,96)`、两列、间距 `124×148`；切页重开仍保留，取消不提交、保存后挑战可用。
- `h5-probe-build.json`：上述已发布探针包的构建时间、基线提交、dirty 状态与实际输入 SHA。它不是交付默认五列源码的产物。

本批完整客户端 24/24 和 strict 通过；收尾文案调整后 formation、formation-view、hero 与 strict 再次通过。业务检查未删除或降低断言。

`formation-local-delivery.log` 曾在刷新后状态仍为空时被固定九秒等待误判为自动进城；该失败保留于临时目录。运行探针改为等待真实登录/主城入口出现，然后检查必须停在登录页，未放宽登录门槛。

用户要求本机优先、暂停 H5 构建后，仅停止隔离工程的最终默认布局构建进程树；驱动退出 1 是用户取消，不计作成功构建。已发布 H5 探针包未被该次中止覆盖，不要求现在再构建。
