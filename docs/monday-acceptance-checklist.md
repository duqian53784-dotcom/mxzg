# 周一验收清单

在 Cocos Creator 3.8.8 里对真服走一遍。预览地址不要带 `?dev=mock`，也不要带 `?transport=mock`。Mock 只在那两个参数后面打开，不能再变成默认。

本仓库没有 Java 服。服由本机 `scripts/start-local-all` 拉起，桥是 `ws://127.0.0.1:13111/game`（TCP 9902）。客户端不本地加减金币、不改关卡、不改星级。

## 开之前

1. 先双击 `scripts/start-local-all`。9902 或 13111 已经在听会自己跳过。
2. Creator 打开 `client`。启动场景保持 Boot。
3. 预览。地址栏不要加 mock。GameLog 里应看到 `stage=version` → `hot-update` → `assets` → `config` → `login` → `sync` → `enter-main`。不应出现 `connect mock://local`。
4. 账号填已经有角色的数字平台 uid。新号走创角。空号也要能进，不要白屏。

通过：加载层盖住选服，连上桥之后才露出选服。点进入之后字仍是「登录」，然后是「同步角色」，八个包齐了才进主城。18 秒没齐会写出缺的号，重试再拉，不把半套数据当成进了主城。

## 4. 挂机

底栏「战斗」进挂机。舞台是 `chapter/hang/map01_B` + `map01_F`，不是一整块黑森林。底栏三钮是战力UP / 战斗 / 高速战斗。

| 看哪里 | 通过 |
|---|---|
| 站场 | 3101 的 MAIN 有英雄时，用名册 `hero_type` 对皮肤。没有英雄时是三套默认 spine，不当成角色，也不写入服。站好之后不用点「战斗」，英雄会自己打：怪在后侧出现，挨打，然后消失，接着下一只。点「战斗」仍进真战报，演武先停 |
| 画面 | 打开就是大理石站场、英雄和演武。探针字（「关- / 关+」「请求战报」「切磋」「再拉 3102」「空壳探针」）只在地址带 `?dev=wire`，或长按挂机左侧空地时出现。`?dev=wire` 仍连 `ws://127.0.0.1:13111/game` |
| 四格 | 当前关 `chapterreward.reward_base`：900001 金币、900101 英雄经验、900003 角色经验，写成「N/m」，条上有填充色。填充宽 158，高度跟原图（宝箱橙条 28，金币和英雄经验 24，角色经验是一条 4 像素的黄线，不是粗色带）。宝箱条是短时钟。当前关 = 3007 的 `nowIdx`，没有再用 `maxIdx`，都没有就是 1。表没绑上写「—/m」且不铺色。场地中央不再是空蓝金匾，也不再有多句「待命」。中间「战斗」钮上有一圈 `btn-battle` 光，大约 2.4 秒转一圈，字仍是「战斗」 |
| 时钟 | 从 `reward_time` 往后走，大约每秒加 1 秒，不会加得比真实时间快一倍。满 1 小时是 `hh:mm`（封顶 21600 秒写成 `06:00`）。不满 1 小时是 `mm:ss`。不是时间戳时写「未同步」 |
| 掉落 | 有 `reward_base` 或 `drop_group` 时，场地上是金币 / 水晶 / 宝箱 / 掉落图标叠成的一堆，计时泡在堆上。堆在金环水晶上沿，不盖住环。没有这些数据时场地留空。不掷随机数，不写进三格 |
| 对白 | 左英雄头顶一枚深色气泡，句子来自 herotalk 对上的 language，按等级过滤，大约 8 秒换一句。不写「待命」。进真战报时藏起来。等级没同步时按 1 级 |
| VIP | 没有角色 VIP 等级时战斗钮下不写字。不把表里的 10% 乘进三格 |
| 宝箱 | 发空 c2s 3005。成功后时钟按新的 `reward_time` 重算，第二行不再停在「已发领取」。金币和道具等随后的 2001 / 5001 / 5002 |
